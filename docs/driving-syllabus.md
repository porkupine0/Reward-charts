## Written (knowledge) test: what the course doesn't do yet (Nov 18)

- **No final test, unit test, pass mark or score.** Each lesson is 5 questions with no pass mark.
- **Coverage follows the videos, not the manual.** Every lesson needs a video (checkCourse), so a section with no video can't carry questions. A lesson a parent skips is never finished, and earlier questions come only from finished lessons, so its questions never come back.
- **Sign pictures:** the quiz is text-only.
- **Iowa DOT practice test** (iowadot.gov, "Take a practice test"): 25 questions drawn from a pool that includes real knowledge-test questions; 80% to pass; repeatable. The real test's length and pass mark aren't confirmed here. The test itself runs on ia.iowadot.gov, which this environment can't reach.
- Hazard-spotting matters for driving, not for the written test.
